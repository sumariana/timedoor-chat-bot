Solution Overview04
04 / Scope

Fitur yang ditawarkan untuk MVP

FEATURE 01

Natural Language Project Query

Query tech stack, project URL, bug counts, status, changelog versi terbaru, dan informasi project lain dalam Bahasa Indonesia maupun English.

FEATURE 02

Live Data Fetching

Mengambil open bug counts, changelog versi terbaru, dan informasi project secara langsung dari sumber Notion.

FEATURE 03

Hybrid Data Routing

Notion API untuk data terstruktur (cepat, cached); Notion MCP sebagai fallback untuk halaman bebas dan konten yang tidak terstruktur.

FEATURE 04

Stateful Conversation Context

Menyimpan 3–5 percakapan terakhir per user per channel. Follow-up query dapat merujuk project sebelumnya tanpa mengulang nama. Session timeout 30 menit.

Termasuk di Phase 1

Read-only retrievalNotion DatabaseDiscordIndonesian & EnglishSession context

Di luar scope MVP

Direct data editing; unstructured file & voice input; granular RBAC; Google Sheets integration; slash commands; proactive alerts/notifications; Redis session persistence.

1-Month MVP Scope05
05 / Architecture

Breakdown module

MODULE 01

Discord Gateway

Authentication, persistent connection, channel filter, mention listener, typing indicator, rate limiter, embed response, error message.

MODULE 02

Query Parser

Session manager, intent classifier, entity extractor, fuzzy matcher, multi-question splitter, language detector.

MODULE 03

Notion Data Router

Workspace registry, Tier 1–3 routing, property normalizer, MCP fallback, explicit not-found signal.

MODULE 04

Data Fetcher

Notion API client, Notion MCP client, page reader, credential extractor, cache layer dengan TTL per data.

MODULE 05

LLM Response Synthesizer

Prompt builder, multi-answer formatter, language instruction, hallucination guardrail, credential formatter, token optimizer.

MODULE 06

Configuration & Observability

YAML config, LLM settings, cache TTL, latency logger, error tracker, audit log, health check endpoint.

07 / Success Criteria

Definisi keberhasilan MVP

< 7s

Response latency

Structured queries (Tier 1/2); MCP queries < 15s (Tier 3).

≥ 90%

Data accuracy

Structured data; ≥ 70% untuk MCP queries (unstructured).

40%

Time efficiency

Pengurangan waktu lookup project.

< $10

Monthly LLM cost

Target biaya operasional LLM per bulan.

Target adoption

Weekly active usage oleh PM, Dev, QA, CS, dan Sales selama trial period.

Risiko utama

Data Notion tidak lengkap, API rate limit, prompt/token cost, data access exposure, dan kebiasaan lama pengguna.
